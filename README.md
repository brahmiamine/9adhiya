# 9adhiya — قائمة الشراء

Application React + Vite en arabe tunisien pour préparer, conserver et partager une liste de courses.

## Développement

```bash
npm install
npm run dev
```

## Vérification

```bash
npm test
npm run build
```

La branche `main` est automatiquement testée, construite puis déployée sur GitHub Pages par GitHub Actions. Vite utilise le chemin de base `/9adhiya/`.
